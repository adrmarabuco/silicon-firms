# Second Evaluation

This folder reports the independent second evaluation of predefined borderline classification cases from the official corpus.

Files:

- `boundary_cases.csv`: row-level results for the evaluated boundary cases.
- `boundary_audit.md`: human-readable summary of the second evaluation.
- `boundary_audit.json`: structured version of the same audit.

The evaluation is restricted to papers already included in the official corpus and does not change the corpus scope.
